# my-guess-game Requirements

## Goal

Build a Pi extension (`pi-extensions/my-guess-game`) that lets the user play a
Yes/No "guess the character" game. The extension generates a secret public
figure, stores it per session, and provides strict Yes/No/Unknown answers and
guess judgement through dedicated tools.

## Must have

- Three tools registered under the extension:
  - `play_guess_game` — starts a new game
  - `ask_guess_question` — answers a Yes/No question
  - `submit_guess` — judges a final guess
- `play_guess_game` supports an optional `category` parameter:
  `any` (default), `science`, `sports`, `history`, `arts`, `fictional`.
- Secret character is generated by LLM with name + one-sentence summary.
- Both real and fictional characters are allowed.
- Game state is stored in memory keyed by `ctx.sessionId`.
- Only one active game per session at a time.
- `ask_guess_question` returns exactly `Yes`, `No`, or `Unknown`.
- Invalid LLM responses in `ask_guess_question` fall back to `Unknown`.
- `submit_guess` reveals the target and history only when the guess is correct.
- Incorrect guesses keep the game active and are recorded.
- Error codes: `no_llm`, `generation_failed`, `game_already_active`,
  `no_active_game`, `invalid_answer`, `ambiguous_guess`.
- TDD: tests before implementation; pure modules target 100% coverage.
- Build via `bunx turbo run build`, deploy via `bun run deploy` to
  `~/.pi/agent/extensions/my-guess-game`.

## Must not

- Persist game state to disk.
- Allow more than one active game per session.
- Answer questions outside the three allowed words.
- Reveal the secret character before a correct guess.
- Depend on external storage or databases.

## Out of scope

- Custom TUI or visual companion integration.
- Multi-session game recovery.
- Scoreboard, statistics, or leaderboard.
- Multi-language target generation (start with Chinese names).
- Automatic uninstall of any existing extension.
