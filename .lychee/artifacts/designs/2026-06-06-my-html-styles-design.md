# my-html 页面样式增强设计文档

**日期**: 2026-06-06
**方向**: 优雅丰富 — Catppuccin Mocha 配色内容排版全面升级

## 概述

在 my-html 扩展现有基础上，添加一层自定义 CSS，覆盖 `github-markdown-css` 的关键样式，全面提升 Markdown 渲染页面的内容排版质量。所有颜色沿用 Catppuccin Mocha 调色板。

## 设计原则

- 在现有 CSS 基础上增量覆盖，不替换 `github-markdown-css`
- 所有颜色严格使用 Catppuccin Mocha 变量值
- 无 JavaScript 交互（除代码块复制按钮外，CSS-only fallback）
- 支持响应式

## 详细设计

### 1. 页面布局

- 背景色: `base` (`#1e1e2e`)
- 最大宽度: 820px（从 900px 缩小，优化行长）
- 内边距: 1.5rem
- 轻量 header: 居中，字体 0.8rem，颜色 `overlay0`，内容 "Pi Agent Reply"
- 轻量 footer: 顶部 1px 分隔线（`surface1`），居中，小字体 `overlay1`，内容 "Generated by pi · Catppuccin Mocha"

### 2. 标题系统

| 级别 | 字号 | 颜色 | 装饰 |
|------|------|------|------|
| H1 | 1.75rem / 800 | 渐变 (`pink` → `mauve` → `blue`) | 左侧 4px `mauve` 竖线 |
| H2 | 1.3rem / 700 | `blue` | 底部 2px `surface1` 实线 |
| H3 | 1.1rem / 600 | `teal` | 无 |
| H4 | 1rem / 600 | `yellow` | 无 |

H1 渐变用 `background: linear-gradient(135deg, #f5c2e7, #cba6f7, #89b4fa); -webkit-background-clip: text; -webkit-text-fill-color: transparent;`。

可选：H1 前通过 CSS `::before` 伪元素添加 emoji 图标（默认关闭，作为可选配置项）。

### 3. 段落

- 字号: 15px
- 行高: 1.75
- 颜色: `text` (`#cdd6f4`)
- 下边距: 1.25rem

### 4. 表格

- 外层: `border-collapse: separate; border-spacing: 0` + 8px 圆角 + 1px `surface1` 外边框
- 表头: `surface0` 背景，`mauve` 色文字，大写 + 0.5px 字母间距，字号 0.85rem
- 斑马纹: 奇数行 `base`，偶数行 `surface0` 微变体（`#232436`，介于 base 和 surface0 之间）
- 行悬停: 背景变为 `surface0`
- 单元格: 水平分隔线 `surface1`，内边距 10px 14px
- 移除垂直网格线

### 5. 无序列表

- 一级: `▸` 标记符，颜色 `teal`，加粗
- 二级: `◦` 标记符，颜色 `yellow`
- 使用 `list-style: none` + `::before` 伪元素实现自定义标记

### 6. 有序列表

- 数字标记: `mauve` 色，加粗

### 7. 引用块 (Blockquote)

- 左侧 4px `mauve` 竖线
- `surface0` 微变背景 (`#232436`)
- 右侧 6px 圆角
- 文字: `subtext1`，斜体
- 内边距: 0.75rem 1rem

### 8. 代码块

- 标题栏: `surface0` 背景 + 底部 1px `surface1` 分隔
  - 左侧语言标签: `teal` 色，大写，0.75rem
  - 右侧复制按钮: `surface1` 背景，hover 时 `surface2`，内含 "📋 复制" 文字

- 复制按钮: 纯 CSS 实现，点击通过 `navigator.clipboard.writeText()` 复制代码文本。复制成功时按钮文字短暂变为 "✅ 已复制"

## 实现策略

### 技术选择

在 `render.ts` 的 `buildHtmlDocument()` 中扩展内嵌 `<style>` 块，追加自定义 CSS 规则。不修改现有的 `github-markdown-css` 和 highlight.js 主题引入方式。

优点:
- 改动集中在一个函数
- 不影响现有构建流程
- 覆盖 github-markdown-css 的默认样式时使用更高特异性选择器

### 关键 CSS 选择器策略

在 `.markdown-body` 上下文内覆盖子元素样式，利用选择器特异性覆盖 `github-markdown-css`:

```css
.markdown-body h1 { /* 覆盖 */ }
.markdown-body table { /* 覆盖 */ }
.markdown-body pre { /* 覆盖 */ }
/* ... */
```

### 代码块复制按钮

在 `buildHtmlDocument()` 中加入内联 JavaScript：

```javascript
document.querySelectorAll('.code-block-header button').forEach(btn => {
  btn.addEventListener('click', () => {
    const code = btn.closest('.code-block-wrapper').querySelector('code').textContent;
    navigator.clipboard.writeText(code).then(() => {
      btn.textContent = '✅ 已复制';
      setTimeout(() => btn.textContent = '📋 复制', 2000);
    });
  });
});
```

代码块 HTML 结构从当前的 `<pre><code>` 改为带 wrapper:

```html
<div class="code-block-wrapper">
  <div class="code-block-header">
    <span>typescript</span>
    <button>📋 复制</button>
  </div>
  <pre><code>...</code></pre>
</div>
```

这需要在 `renderMarkdownToHtml` 之后对 HTML 做后处理，将 `<pre><code class="hljs language-xxx">` 的代码块包裹在 wrapper 中，并提取语言名。

### 不做的事项

- 不替换 `github-markdown-css` 为自定义主题
- 不添加行号
- 不添加目录 (TOC) 自动生成
- 不添加暗色/亮色切换
- 不引入额外 CSS 框架或图标库
- emoji 标题前缀默认为关闭，作为可选配置项（不做默认开启）
- 不处理 `my-html.json` 中的配置项扩展（如开启/关闭 emoji 标题）
