# my-hud 需求确认清单

## 我要什么

### 1. aboveEditor — 运行状态仪表盘

**核心信息（窄屏时优先保留，宽屏尾随）**：

1. **模型** — 当前使用的 LLM，通过 JSON 映射表显示短名，无映射时显示原始 ID
2. **上下文%** — 窗口使用率，带颜色阈值和电池图标
3. **Input / Output** — 累计 token 数

**次要信息（宽屏时显示，窄屏截断）**：

- 项目名（basename，>10 字符截断为前 8 + `..`）
- Git 分支（为空时整字段隐藏）
- **Git 变更文件数**（新增，放在 Branch 旁边，如 `main(+3)`）
- Cache Read tokens
- Cost（CNY，保留两位小数）

**截断策略**：

- 超长项目名：前 8 + `..`
- 整行超长：`truncateToWidth` 尾部截断
- 窄屏（如 ≤60 字符）：保证「模型 + 上下文% + Input/Output」可见，其余截掉

### 2. footer — 上下文锚点

- 显示**最后一条非空用户消息**的纯文本摘要
- 前缀终端图标 ``，颜色 `dim`
- 无用户消息时 footer 留空（不占用行）
- 支持字符串 / array 内容，非 text 部分替换为 `[MEDIA]`

### 3. working — 情绪反馈

- 纯 casual / funny，中文为主，带 Nerd Font 图标
- 每回合 `turn_start` 时随机选择一条
- 通过 `setWorkingMessage()` 设置，优先主题色 `accent`
- 越 funny 越好，不承载技术状态信息

### 4. 配置化模型映射（新增）

- 配置文件：`my-hud.json`（与扩展目录同级）
- 格式：`{ "modelShortNames": { "kimi-k2-thinking": "k-tkg", ... } }`
- 无映射时回退原始模型 ID
- 支持热重载（`/reload` 时重新读取）

## 我不做什么（明确排除）

| 功能 | 排除原因 |
|------|----------|
| 显示当前调用的工具名称 | 动态执行状态，与 aboveEditor "静态身份卡"定位冲突 |
| 显示当前时间 / 已运行时间 | 时钟功能，与 session 状态无关 |
| 显示网络连接状态 / 延迟 | 系统监控，不属于 pi agent 上下文 |
