# Architecture Decision Records

每个决策一个文件，命名为 `<四位编号>-<kebab-case 标题>.md`。编号按创建顺序递增、全局唯一，一经分配不再复用；新编号取目录内当前最大值加一。

每份 ADR 描述**当前有效**的决策、它的理由与被否决的替代方案。实现形态演进时就地更新正文，不保留「曾经是这样」的叙述。文件名同样描述当前主题，例如形态从包变为目录时随之去掉 `package`。

只有决策被明确推翻、现行做法与之相反时，才在标题正下方加一行引用块标注：

`> **Status: Superseded** —— <被什么取代、现行机制在哪>。`
